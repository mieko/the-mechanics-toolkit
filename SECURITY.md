# Security

These transforms modify a local desktop application and therefore run inside a high-trust process.
Use a disposable staged copy, inspect the selected source, keep a recoverable official application,
and treat every new Codex build as unsupported until its exact owners and behavioral probes pass.
A green static proof is not live acceptance.

Report toolkit vulnerabilities through GitHub's private vulnerability-reporting feature. Please do
not attach ChatGPT/Codex bundles, extracted ASAR trees, credentials, profiles, task databases,
private configuration, or unredacted logs and screenshots. Describe the affected toolkit revision,
patch, recognized Codex version/build, reproduction boundary, and plausible impact with the minimum
necessary synthetic evidence.

Upstream ChatGPT or Codex vulnerabilities belong in OpenAI's reporting channel, not this repository.
